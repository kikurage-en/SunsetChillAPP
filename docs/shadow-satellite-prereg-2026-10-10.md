## 雲判定 (固定値、結果を見て変えない)
- 格子: 緯度経度 0.02° 刻みの最近傍画素。
- 晴天参照 ref: 各格子点・各時刻系列について、**前日までの15日**の B13 最大値。
- 雲画素: BT < ref − 5K。
- 層: 雲画素のうち BT < 255K = 上層、255〜273K = 中層、≥ 273K = 下層(赤外は最上層しか見えないので、上層の下の下層雲は数えられない)。
- 地点の雲量 = その地点を中心とする ±0.05° 箱内の雲画素の割合(%)。地点は本番と同じ近似方位: 20km(near)、40km(far)、経路 40/50/60/80/100km。

## 候補 (3つだけ)。雲以外の入力 (降水確率・視程・風・雨シグナル) は同じ日の本番ログ行 (17:00、無ければ13:00)
- **C1 置換**: 本番式に衛星の層別雲量を入れる。cc・low は far(40km)、mid・high は near(20km)。
- **C2 経路max**: C1 の cc だけを経路 40〜100km の箱雲量の最大に置き換える。
- **C3 遮蔽キャップ**: 既存の本番式スコア(ログ値)に、経路 40〜100km の箱雲量の平均が ≥85% なら min(・,30)、≥70% なら min(・,65)(本番の総雲量キャップと同じ閾値)。

## 比較基準
- **主基準(C1・C2 用)**: 現行の本番式 + ログに残る本番の西空雲量 (17:00行の `sunset_cloud_*`、雲以外の入力も同じ行)。Δρ を雲の入力の差だけにするため。
- **既存予測(副、C3 の基準も)**: ログの本番式スコア (`sunset_score`、式改訂の差を含む) と表示スコア (`final_sunset_score` = min(Vision, 式))。

## 評価
- 真値: L1 = 空の色の画素スコア (sky_color v3、AIに依存しない)、L2 = Gemini 採点。日没枠と残照枠それぞれ。
- 主指標: Spearman ρ。候補 − 既存式 の Δρ を日単位ペアブートストラップ (2000回) で 95%CI。
- 副指標: 鮮やかな日の AUC (L2 ≥ 70、L1 は上位20%)、前半 (07-20〜08-31) / 後半 (09-01〜10-09) の符号の一致。
- 判定: 本番採用はこの結果だけでは行わない (陽性日 N≈9〜13 で AUC の CI が ±0.1 程度)。
  「有望」= 両ラベルで Δρ > 0、前後半とも同符号、少なくとも一方のラベルで CI が 0 を含まない。それ以外は「根拠なし」。
- 感度分析 (選択には使わない): ΔT = 3K / 7K、箱 ±0.03° / ±0.08°。

## 既知の限界 (結果を見る前に記す)
- (a) 陸上の晴天参照: 15日最大値は、晴れていても地表が冷えた日を「下層雲」と誤判定しうる(BT ≥ 273K かつ < ref−5K)。秋と、季節を通じて陸上にある 40km 点(C1 の cc・low の入力)で最も起きやすい。診断列として、固定の海上箱(相模湾 35.15N 139.40E)と陸上箱(丹沢 35.45N 139.15E)の下層雲判定率を出す。ΔT=7K の感度分析も一部これを見る。
- (b) B13 だけでは薄い巻雲(気温低下が5K未満のことが多い)を見落とす。これは本番式で +10 の上層雲ボーナスの対象。C1 の上層雲項が効かなくても「B13 v1 では検出できない」であって「衛星が役に立たない」ではない。診断列として、BT13−BT15 ≥ 2.5K かつ B13 で雲でない画素の割合(near 箱)を出す。
